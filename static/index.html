카카오맵 지도 로드 오류 해결 가이드

현재 `.env`에 정의된 카카오 JS API 키가 존재하지만, 브라우저 환경에서 카카오 지도 서버(`dapi.kakao.com`)로의 스크립트 연결이 차단되었습니다. 지도를 띄우기 위해 아래의 3가지 필수 설정을 확인해 주세요.

1 카카오 Developers 플랫폼에 도메인 등록하기

카카오맵 API는 보안을 위해 사전에 등록한 Web 도메인에서만 지도를 불러옵니다.

  1. 카카오 디벨로퍼스 콘솔에 접속 및 로그인
  2. [내 애플리케이션] → 해당 앱 선택 → 왼쪽 메뉴의 [플랫폼] 클릭
  3. [Web] 항목의 '사이트 도메인' 등록/수정 버튼 클릭
  4. 아래 도메인들을 한 줄씩 추가 후 저장:
    ▸ Vercel 배포 도메인 (필수)
    https://apt-lime-eight.vercel.app
    ▸ 로컬 개발 도메인 (선택)
    http://localhost:8000
    http://127.0.0.1:8000

    저장 후 카카오 서버 반영까지 최대 1~2분이 소요됩니다. 저장 후 새로고침 해주세요.

2 브라우저 광고 차단기 및 Brave Shields 해제

uBlock Origin, AdBlock 등 광고 차단 확장 프로그램 또는 Brave 브라우저 자체 보호막(Shields)이 카카오 지도 파일(`dapi.kakao.com`)을 추적 트래커로 판단하여 차단할 수 있습니다.

주소창 옆의 광고 차단기 아이콘을 클릭하여 "이 사이트에서 차단 안 함" 또는 "보호 기능 비활성화"로 예외 처리한 후 새로고침(Ctrl + F5) 해주세요.

3 API 키 값 확인 및 검증

`.env` 파일의 `[kakao] js_key` 값이 카카오 개발자 콘솔의 [JavaScript 키]와 완벽히 일치하는지 확인해 주세요. (REST API 키는 사용할 수 없습니다)
